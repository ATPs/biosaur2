# Biosaur2 0.6.1

## Hybrid output-format correction

Hybrid output now follows `--format` consistently for all public tables.
`--format parquet` writes only the feature and identification Parquet files,
instead of also writing a duplicate identification TSV. `--format tsv` writes
the corresponding two TSV files, while `--format duckdb` writes only the
per-input database.

The identification schema is unchanged. In particular,
`canonical_peptidoform` remains available alongside `peptide_raw` because it
preserves normalized and fixed modification notation needed by downstream
identity matching.
